# 実装状況

更新日: 2026-08-13

この文書はプロトタイプの現在地を記録する。製品として守る判断基準は [UI_UX_POLICY.md](UI_UX_POLICY.md) を参照する。

## 実装済み

- 対象件数を予告する最小確認画面
- 分類グループ、最優先ドメイン、色、`Others`、補助分類の設定
- 親子ドメインの併用と最長一致優先
- ページ内容による補助分類の30タブ上限、3並列、全体3秒予算
- 補助分類トグル直後の任意権限確認、拒否時の即時復帰、未保存離脱時の権限回収、外部権限解除の検出と実行予告への反映
- 完了画面のグループ／タブ一覧と、1操作での誤分類訂正
- 誤分類訂正メニューの排他的開閉、候補へのフォーカス移動、矢印キー／Esc操作
- Ctrl+Z / ⌘Zで行う30分間のUndo。OSに応じた表示、ポップアップ再表示、Service Worker再起動に対応
- 完了画面を開いたまま30分を過ぎた場合のUndo・分類修正・設定画面ヒントの自動失効と安全なフォーカス移動
- 操作IDを照合するUndoと5分間の成功レシート。古い画面からの誤Undoと応答喪失後の二重実行を防止
- 実行前確認の状態トークン。確認後にタブ・分類設定・必要な権限が変わった場合は何も動かさず最新件数へ戻し、実行開始直後に増えたタブも対象外にする
- 実行中ロック、途中復元ジャーナル、ユーザーが後から動かしたタブの保護
- 再起動後の所有グループ再検証。同名候補が曖昧な場合は重複を作らない
- 設定タブの再利用、短い待ち時間でまとめる自動保存、保存状態表示、直前の自動保存を戻す1段階復元、保存待ちの離脱確認
- 完了画面や別の設定タブからの設定更新を自動反映し、編集中の競合は保存前にも再検証して上書きを防止
- 整理・再構成・グループ編集の応答が途切れた場合、実行中状態または新しいUndo記録から結果を自動照合
- 遅い状態応答を重ねず、再開始・終了後の古い応答を描画しない単一リクエスト式の処理中ポーリング
- 設定画面の一時的な状態取得失敗で一覧・選択・Undo表示を消さず、変更操作を止めたまま有限回で自動復帰
- 分類グループと現在のタブグループ一覧の再描画後も、同じ操作位置または安全な代替項目へキーボードフォーカスを復元
- 両一覧を一つのTab停留点にまとめ、上下矢印・Home・Endで選択と分離したフォーカス移動
- 分類設定の世代付き分割保存。従来形式を自動移行し、容量超過や途中失敗でも直前の設定を維持。外観・動作だけの自動保存では分類チャンクの再書込みを省略
- 分類ルールと整理動作の共通正規化。旧形式で `enabled` がない分類も有効のまま引き継ぎ、UI Labと実拡張で同じ既定ルールを使用
- 分類グループ単位の使用／停止。停止中表示、使用中件数、ドメインと色を保持した再有効化に対応
- 720px以下の縦積み設定レイアウトと、320pxまでの横スクロール抑制
- 左上の作業名から切り替える `分類設定`／`タブグループ整理`
- 現在のグループ一覧、選択グループ内のタブ確認、確認付きのウィンドウ整理とCtrl+Z / ⌘Z
- 設定画面の確認中に状態が変わった場合、ダイアログを閉じず最新件数へ差し替える再確認導線。ダイアログ中に保留した一覧更新も終了直後に反映
- 選択グループだけの再構成。元グループと判定不能タブを保護し、確認後の変更検出とCtrl+Z / ⌘Zに対応
- 既存グループの名前・色・折りたたみ状態の直接編集。外部変更検出、所有権追従、途中復元、Ctrl+Z / ⌘Zに対応
- Customテーマのライト／ダーク自動生成とコントラスト保証

## 自動テスト

Nodeのテストで次を検証している。

- 最長ドメイン一致
- 補助分類の権限・上限・段階読み取り・全体予算
- 完了画面からの訂正とUndoの連携
- 所有グループの再起動後照合と曖昧候補の保護
- Undoの復元、手動変更の保護、途中中断、30分の失効
- UI側の期限計算、期限切れ・欠損値・長時間タイマー境界
- 処理中ポーリングの遅延応答、再開始、一時失敗、停止後応答の破棄
- 状態更新の有限再試行、成功・手動更新後の再試行間隔リセット
- 再描画前の項目、選択項目、先頭項目の順で決めるフォーカス復元先
- 縦一覧で左右矢印を奪わず、上下・Home・Endだけを循環移動に使う規則
- 古いUndo操作IDの拒否、応答喪失後の同一Undo再送、操作結果の状態照合
- 確認トークンの安定性とタブ・設定・権限変更の検出、確認後に増加・変化したタブの保護
- 設定画面の確認文言、状態変更後の再確認、0件時に補助分類を実行できる条件
- 選択グループ再構成の最小移動、既存所有グループの再利用、状態変更時の中止、失敗時ロールバック
- グループ表示編集の入力検証、共有グループ保護、所有権保存失敗時のロールバック、途中中断、Undo競合保護
- Customテーマの4.5:1／3:1基準を4,096基準色×ライト／ダークで検査
- 分類設定の8KB超分割、日本語のバイト境界、従来形式移行、保存失敗時の旧世代維持
- 分類ルールの欠損値・不正値・重複IDと、旧形式の有効／無効状態の互換性
- 停止した分類が通常判定・補助分類・再構成・訂正候補から除外されること
- 自動保存後の1段階復元、保存待ちの破棄、保存中に重なった編集、外部更新時の履歴破棄

## 制約

- Undoは `chrome.storage.session` を使うため、ブラウザーを終了すると消える。永続履歴ではない
- タブやグループをユーザーが整理後に変更した場合、Undoはその変更を優先して対象をスキップする
- Chromeの現在のテーマ基準色を拡張機能から取得する公開APIはないため、完全な自動同色化はできない
- 共有タブグループは共有先への影響を避けるため、再構成と直接編集の対象外
- 分類設定はChrome同期領域の総容量内で保存する。上限を超えた変更は画面に残し、既存設定を置き換えない
