# 既存タブグループの直接編集

実装日: 2026-08-13

`タブグループ整理` で選択した通常グループの表示属性だけを編集する。

## 対象

- 名前。空欄も許可し、表示上は「名称なし」と扱う
- Chrome標準の9色
- 折りたたみ状態

グループ順、所属タブ、結合、解除は目的と復元範囲が異なるため含めない。

## UX

- 選択グループの上部アクションから小さなモーダルを開く
- 保存するまでChromeへ反映しない
- 変更がない間は保存できない
- 色はクリックに加え、矢印・Home・Endキーで選択できる
- 保存後は設定画面とポップアップのどちらからでもCtrl+Z / ⌘Zまたは元に戻す操作を利用できる

## 安全条件

- 編集開始時の名前・色・折りたたみ状態・ウィンドウが変わっていたら中止する
- 共有タブグループは変更しない
- 実行中ロックと復元ジャーナルを先に保存する
- Service Workerが更新直後に停止しても、未確定操作として復元する
- 所有グループの名前と色を変えた場合は所有権記録も同時に更新する
- 所有権保存に失敗したらグループ表示を即時ロールバックする
- Undo後にユーザーが再変更していた場合は上書きしない
