# 選択グループの再構成

実装日: 2026-08-13

`タブグループ整理` で選択した一つのグループだけを、現在の分類設定に基づいて再構成する。

## 採用した動作

選択グループのタブだけを入力として再分類し、結果が複数カテゴリになる場合だけグループを分割する。別グループや未グループのタブは触らない。

確認には次だけを表示する。

- 対象グループ名とタブ数
- 維持されるタブ数
- 別グループへ移る予定数
- 新しく作る予定のグループ数

## 守る条件

- 元グループを拡張機能所有として扱わない
- 共有タブグループは変更対象にしない
- 判定できないタブを元グループから追い出さない
- ユーザーが整理中に動かしたタブを上書きしない
- 操作全体を一つのCtrl+Zで復元する
- 名前だけで別グループを再利用しない
- 補助分類は通常整理と同じ30タブ・3秒予算を使う

## 決定

1. 元グループに対応する分類が分かる場合、その分類のタブはその場に維持する
2. 対応する分類が分からない場合、最大の分類まとまりを維持して移動量を最小にする
3. 判定不能タブを含め、元グループを必ず残す。名前・色・折りたたみ状態は変更しない
4. 「選択グループへ集め直す」逆方向の操作は含めない
5. 確認には、残る件数、移る件数、移動先数、新規グループ数だけを表示する

元グループを残し、分類先が明確なタブだけを外へ移す。確認後に名称・色・タブ構成・URL・タイトルが変わった場合は実行せず、再確認を求める。

## 次に分けて検討する機能

- 選択グループへタブを集め直す操作
- グループ名、色、折りたたみ状態の直接編集
- 複数グループの結合と解除

いずれも再構成とは目的と破壊範囲が異なるため、同じボタンへ統合しない。
